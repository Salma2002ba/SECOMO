# SECOMO

Prototype POC — Serre connectée modulaire (SECOMO Innov 2026).

## Lancer l'app

```bash
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000) dans le navigateur.

## Autres commandes

- `npm run build` — build production
- `npm run preview` — prévisualiser le build (après `npm run build`)
